# Samartify Frontend

Samartify is a Next.js storefront for browsing machine embroidery designs. It includes paid, free, and reward-based designs, with pages for shopping, product details, cart, checkout, and customer accounts.

## Features

- Browse designs by category, popularity, and arrival date
- Search, sort, and filter the product catalog
- View design details, including hoop sizes, stitch counts, formats, and license options
- Add products to a cart or wishlist
- Explore free designs and designs available through reward points
- View account, order, download, and rewards pages
- Use the responsive layout on desktop and mobile screens

## Tech Stack

- Next.js and React
- TypeScript
- Tailwind CSS
- Radix UI components
- Lucide icons

## Getting Started

### Requirements

- Node.js and npm

### Run locally

1. Clone this repository:

   ```bash
   git clone https://github.com/codeplane1016/samartify-frontend.git
   cd samartify-frontend
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000).

To create a production build, run:

```bash
npm run build
npm run start
```

## Project Status

This repository is a frontend demonstration. Product information is generated in the project, and cart and customer state use browser storage. Checkout and account screens should not be treated as a production payment or authentication system.
